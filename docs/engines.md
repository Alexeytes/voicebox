# Движки озвучивания

Интерфейс движка описан в app/tts/base.py.

## Edge Neural

Используется по умолчанию при доступности голоса. Даёт нейронное произношение и параметры темпа. Обычные стандартные голоса не предоставляют управление эмоциями; pitch не меняется ради имитации выражения. Результат зависит от доступности облачной службы.

## gTTS

Резервный базовый вариант для русского и английского, менее выразительный. Выбирайте его только если подходит качество.

## Azure MAI-Voice-2.1

Опциональный русский движок с SSML style для нейтрального, вдумчивого и серьёзного чтения. Задайте AZURE_SPEECH_KEY и AZURE_SPEECH_REGION. Облачный доступ может тарифицироваться; проверяйте права аккаунта.

Стандартные и expressive голоса — разные возможности. В официальной таблице Azure указано, что для русских стандартных голосов стили не перечислены, а для MAI-Voice-2.1 доступны стилевые режимы: [языки и голоса Azure Speech](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=text-to-speech).

## Добавление движка

1. Создайте модуль в app/tts и унаследуйте TTSEngine.
2. Верните Voice-объекты и реализуйте async synthesize(text, voice_id, style).
3. Блокирующий SDK-вызов выполняйте через asyncio.to_thread.
4. Зарегистрируйте движок в get_all_engines() и engine_for_voice(); ID должен иметь префикс engine:.
5. Логируйте traceback сервером и возвращайте ясное состояние задачи; не переключайте голос скрыто.
6. Обновите конфигурацию, документацию и ограничения.

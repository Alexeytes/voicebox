# Voice Box

Сервис преобразует вставленный текст и электронные книги в аудио MP3. Интерфейс даёт выбрать голос и манеру, проверить образец, следить за ходом синтеза и скачать результат.

- Входные форматы: TXT, поисковый PDF, DOCX, EPUB, FB2, ODT, HTML, RTF и Markdown; сканированные PDF требуют OCR и сейчас не поддерживаются.
- Русские и английские голоса: Edge Neural и gTTS; Azure MAI доступен при настройке учетных данных.
- Статистика синтеза и рекламных баннеров доступна администратору.
- SQLite, локальный ограниченный worker queue и Docker.

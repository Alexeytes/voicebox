# Тестирование

Тесты хранятся в tests/: проверяют главную страницу, каталог голосов, выдачу превью на подменённом движке и разбиение длинного текста. Тесты API используют отдельную временную SQLite-базу и не обращаются к внешнему TTS.

Локально установите зависимости разработки и выполните:

```sh
python -m pip install -e ".[dev]"
python -m pytest
python -m ruff check app tests
python -m mkdocs build
```

Проверка 2026-10-23: 7 тестов прошли, Ruff сообщил об отсутствии проблем, MkDocs собрал сайт. В оставшейся проверке нужны дополнительные сценарии для auth, очереди, статистики и CRUD баннеров; эти пункты оставлены в roadmap.

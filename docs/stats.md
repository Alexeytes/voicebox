# Статистика

Страница /admin/ отображает статистику из таблицы stats_events: запросы и результаты синтеза, ошибки, среднее время обработки, популярные голоса, активные баннеры, показы, переходы и CTR. IP в middleware сохраняется в виде SHA-256 с серверной солью. Не используйте слабый IP_HASH_SALT.

Метрика относится к одной БД; просмотры баннеров считаются при каждом запросе рекламного места и периодическом обновлении слота. События не дедуплицируются. Добавьте срок хранения/агрегацию перед использованием при большом трафике.

В разделе журнала можно фильтровать тип события и листать страницу по 50 записей. Очистить старые события: python -m app.admin prune-stats --older-than 90d. Экспорт: python -m app.admin export-stats stats.csv.

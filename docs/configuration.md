# Конфигурация

Скопируйте .env.example в .env. Обязательные значения: IP_HASH_SALT — случайная соль для хеширования IP; SECRET_KEY — случайный ключ подписи cookie; ADMIN_PASSWORD — секретная строка для сценариев установки. Создайте учетную запись отдельной командой администратора. Не публикуйте .env.

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| MAX_TEXT_LEN | Лимит вставляемого текста | 10 000 символов |
| MAX_CHUNK_LEN | Максимальный размер части для TTS | 3 000 символов |
| MAX_QUEUE_SIZE | Ожидающие задачи | 10 |
| NUM_WORKERS | Количество процессов синтеза | 1 |
| JOB_TTL_SEC | Время хранения готового результата | 3 600 секунд |
| RATE_LIMIT_REQUESTS / RATE_LIMIT_INTERVAL_SEC | Ограничение синтеза по IP | 5 / 60 секунд |
| PREVIEW_RATE_LIMIT / PREVIEW_INTERVAL_SEC | Ограничение превью | 3 / 60 секунд |
| SYNTHESIS_TIMEOUT | Таймаут на часть | 180 секунд |
| CLEANUP_INTERVAL | Частота уборки старых результатов | 300 секунд |
| ADMIN_SESSION_TTL | Срок сессии администратора | 7 дней |
| HTTPS_ONLY | Флаг Secure для cookie | false для локальной разработки |
| TRUST_PROXY | Доверие X-Forwarded-For | false |
| AZURE_SPEECH_KEY / AZURE_SPEECH_REGION | Необязательный Azure Speech с выразительными стилями | пусто |
| ADMIN_USERNAME / ADMIN_PASSWORD | Начальная учетная запись; создаётся при запуске только с непустыми безопасными значениями | обязательны |

Значения секретов замените длинными случайными строками перед развёртыванием. Edge Neural и gTTS обращаются к внешнему сервису синтеза; при отключённой сети озвучивание недоступно.

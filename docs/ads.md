# Рекламные баннеры

В панели выберите изображение PNG, JPEG, GIF или WebP до 3 MiB, укажите название, описание, целевой HTTPS/HTTP URL, вес и размещение (top, between, sidebar или bottom). Каждый слот выбирает одну активную кампанию случайно с учётом веса. На странице размещены три независимых слота с обновлением через заданный в настройках интервал (10–600 секунд).

API считает запрос слота как показ и фиксирует клики через внутренний redirect. CTR показывается в панели. Это собственная баннерная система: она не подключает рекламную сеть и не обеспечивает автоматический биллинг/продажу показов. Для запуска заполните кампании вручную через админку. Кампании не истекают по времени через UI; поля active_from/active_to поддерживаются схемой БД, но пока не редактируются в панели.

## Принятые решения

- [TTS] Edge Neural стал бесплатным голосом по умолчанию: старый UI ставил gTTS первым, поэтому речь звучала механически. gTTS остаётся явным запасным выбором, без скрытого переключения качества.
- [TTS] Для настоящих выразительных стилей добавлен Azure MAI-Voice-2.1 как отдельная платная опция. Стандартные Edge голоса не выдают изменение pitch за эмоцию.
- [Uploads] Добавлены TXT, PDF, DOCX, EPUB, FB2, ODT, HTML, RTF и Markdown. Для сканированных PDF оставлен явный OCR-roadmap.
- [Queue] Очередь оставлена asyncio/in-memory и ограничена одним процессом; это соответствует лёгкой SQLite архитектуре исходного проекта.
- [Ads] Реализована собственная взвешенная баннерная система вместо внешнего рекламного SDK; интеграция выставления счетов не входила в доступные требования.
- [Security] Первый пользователь создаётся из переменных окружения лишь при безопасном пароле; шаблонные секреты не должны автоматически становиться учетными данными.
- [Cleanup] Удалены legacy prototype, статическая сборка документации, тестовые аудио, кэши и одноразовые introspection-скрипты; SQLite, .env и пользовательские mp3 сохранены.
- [Verification] 7 тестов проходят; Ruff и сборка MkDocs проходят. Docker и внешний сетевой синтез не проверялись.

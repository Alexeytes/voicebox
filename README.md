# Voice Box

Веб-приложение для превращения текста и электронных книг в MP3. Интерфейс поддерживает вставку текста и загрузку TXT, searchable PDF, DOCX, EPUB, FB2, ODT, HTML, RTF, Markdown. Можно выбрать язык, голос, послушать превью и скачать результат.

## Локальный запуск

Нужны Python 3.11+, FFmpeg и доступ к сети для Edge TTS.

    python -m venv .venv
    source .venv/bin/activate
    pip install -e ".[dev]"
    cp .env.example .env
    # задайте обязательные случайные значения секретов в .env
    make run

Откройте http://127.0.0.1:8000. Первый администратор создаётся при запуске из безопасных значений ADMIN_USERNAME/ADMIN_PASSWORD. С шаблонным .env создайте его вручную: python -m app.admin create-user admin.

Для бесплатного нейронного чтения используется Edge Neural; gTTS оставлен как резервный базовый вариант. Для управляемой выразительной интонации добавьте Azure Speech key и region в .env — доступ может тарифицироваться.

Подробности API, ограничений форматов, движков, конфигурации и запуска находятся в docs/.
